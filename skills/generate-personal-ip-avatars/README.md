# 专属个人 IP 角色盲盒生成器

这是一个面向零基础用户的 Codex Skill。它主要服务于“不懂绘画、没有艺术细胞、不会配色，但想设计自己专属 IP 角色”的人。

一次生成很多图片并不是为了浪费生成额度，而是把原本需要插画师反复沟通、试色和提案的过程，变成一次可直观看完的角色探索：用户可以像开盲盒一样，从不同配色、动作、发型处理和标志性配饰里找到最适合自己的方向，再挑选喜欢的方案继续精修。

## 它会做什么

- 从一张清晰人物照片中提取可辨识的脸型、五官、发型、轮廓和视觉呈现线索。
- 保持统一的手绘蜡笔、白色剪纸轮廓和稚拙卡通画风，不生成写实头像。
- 自动适配男性、女性、中性、非二元或外观线索不明确的人物，不从风格参考图复制蝴蝶结、领带、首饰等身份特征。
- 默认随机抽取 8 套主题色，每次使用都像打开新的主题盲盒。
- 每套主题色设计 8 张不同方案，发型处理、动作、服装和标志性配饰都会变化，不只是换颜色。
- 最后把全部独立图片拼成一张总览图，便于一次看完、比较和挑选。

## 生成数量

完整模式默认生成：

- 经典基准组：8 张
- 随机主题组：8 组 × 8 张 = 64 张
- 默认合计：72 张

如果已有一组满意的经典 8 张，可以要求保持它们不变，只新增随机主题的 64 张。

如果用户主动说明喜欢的颜色或主题，例如“我喜欢墨绿”和“再加一组橙蓝撞色”，这些主题会追加在随机 8 组之后，不会替换随机盲盒。每追加一个主题会多生成 8 张，因此总数为：

```text
完整模式：72 + 8 × 用户追加主题数量
扩展模式：64 + 8 × 用户追加主题数量（另加保持不变的经典 8 张）
```

## 使用方法

安装 Skill 后，新建 Codex 会话，上传一张清晰人物参考照并发送：

```text
使用 $generate-personal-ip-avatars，根据我的照片生成完整的个人 IP 角色盲盒。
请随机设计 8 套主题色，每套生成 8 张不同动作、发型处理、服装和标志性配饰的图片，最后把全部图片拼成一张总览图。
```

指定喜欢的主题色：

```text
使用 $generate-personal-ip-avatars 生成完整个人 IP 盲盒。
随机 8 套主题保持不变，并在后面额外增加“森林墨绿”和“橙蓝撞色”两个主题，每个主题 8 张，最后生成全部图片总览。
```

已有经典 8 张时：

```text
使用 $generate-personal-ip-avatars，保持我现有的经典 8 张完全不变。
重新随机设计 8 套主题色并新增 64 张；我还喜欢紫金配色，请再追加一组 8 张。最后把现有图片和新增图片全部拼成总览。
```

只想先体验时，可以发送：

```text
使用 $generate-personal-ip-avatars，仅生成经典组 8 张。
```

## 输出内容

- 每个方案都是独立方形 PNG，不用从九宫格里裁切。
- 每个 8 张主题都有单独的 `00-overview.png`。
- `00-all-images-overview.png` 直接包含最终交付的全部原图；扩展模式也会把保持不变的经典 8 张纳入总览，便于快速比较。
- `PROMPTS.md` 记录随机种子、主题抽取结果、用户追加主题和完整设计稿。
- `QA.md` 记录数量、尺寸、重复图片和原经典组哈希检查。

随机种子会被保存，因此同一次任务遇到技术故障时可以恢复原来的盲盒，不会偷偷换一套主题。

## 依赖

图片由 Codex 内置图片生成能力逐张生成。总览拼图使用 ImageMagick；如需自动制作总览，请确保系统可以运行 `magick` 命令。
