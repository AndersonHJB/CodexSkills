# 专属个人 IP 角色盲盒生成器

这是一个给零基础用户使用的 Codex Skill。你不需要会画画、懂配色、写提示词或有“艺术细胞”，只要提供一张清晰人物照片，就能获得可以直接比较和挑选的完整个人 IP 角色方案。

批量生成不是为了浪费生成额度，而是把插画师通常需要多轮完成的试色、动作提案、全身设定、角色转面和表情设计集中呈现。你可以像开盲盒一样发现意外适合自己的方向，再挑选少量方案继续精修。

## 默认会生成什么

所有功能默认开启。默认包含 1 个经典主题和 8 个随机主题，共 9 个主题角色。每个主题角色生成：

- 8 张不同动作、发型处理、服装和标志性配饰设计
- 1 张正面全身照
- 8 张不同角度的全身角色转面照
- 24 张完整情绪图

因此默认数量为：

```text
每个主题：8 + 1 + 8 + 24 = 41 张
默认主题：1 个经典主题 + 8 个随机主题 = 9 个
默认总数：9 × 41 = 369 张独立图片
```

这里的“每个角色”指每个主题中的同一个标准 IP 角色，不会把 24 种情绪再乘到每一张动作图上。这样既能覆盖角色系统，又避免无意义地膨胀到数千张。

如果你觉得 369 张太多，请在开头关闭不需要的功能。Skill 的价值正在于可以自由组合，而不是强迫所有人都生成相同数量。

## 功能开关

你可以在请求开头复制下面的内容，把“开”改成“关”。没有写出的选项仍然按默认“开”处理。

```yaml
功能开关:
  经典主题组: 开
  随机主题组: 开
  基础动作设计: 开
  正面全身照: 开
  八角度角色照: 开
  全面情绪包: 开
  分组拼图: 开
  全部图片拼图: 开
随机主题数量: 8
喜欢的主题色: []
```

也可以直接说自然语言，例如：“不要情绪包，只要正面全身和八角度角色照”。当你使用“只要”时，没有点名的图片模块会关闭；质检功能始终保留。

## 一键复制：自定义功能与喜欢色

用户喜欢的主题色会追加在随机主题之后，不会替换随机盲盒。每个追加主题按照当前开启的模块增加对应图片数量。

```text
使用 $generate-personal-ip-avatars，根据我的照片生成 IP 角色。

功能开关:
  经典主题组: 开
  随机主题组: 开
  基础动作设计: 关
  正面全身照: 开
  八角度角色照: 开
  全面情绪包: 开
  分组拼图: 开
  全部图片拼图: 开
随机主题数量: 8
喜欢的主题色:
  - 森林墨绿
  - 橙蓝撞色

请保留随机的 8 套主题，并在后面追加我喜欢的两个主题。
```

这套配置每个主题生成 `1 + 8 + 24 = 33` 张，共有 `1 + 8 + 2 = 11` 个主题，总计 `363` 张。

Skill 会先记录原经典图的 SHA-256，把新增文件写入独立目录，不覆盖、重命名或重新压缩旧图。

## 八角度全身转面包含哪些方向

每个启用主题生成以下 8 张独立、头到脚完整入镜的角色转面照：

1. 正面
2. 左前 45°
3. 左侧面
4. 左后 45°
5. 背面
6. 右后 45°
7. 右侧面
8. 右前 45°

不是把图片左右翻转冒充新角度；不对称的头发、衣服和配饰会按空间关系正确变化。

## 24 种情绪

情绪包包含：平静中性、放松、开心、大笑、兴奋、自豪、感激、如释重负、好奇、专注、坚定、惊讶、疑惑、害羞、尴尬、担心、害怕、伤心、哭泣、生气、不耐烦、嫌弃、疲惫和无聊。

每种情绪都是独立方形图片，并保持同一角色的脸型、发型、服装、主题色和构图一致。

## 随机主题盲盒

- 每次新任务都会得到新的随机种子和新主题组合。
- 随机主题会覆盖不同色相、明暗、冷暖和情绪氛围，不使用固定的八套预设。
- 随机种子和主题抽取结果会写进 `PROMPTS.md`。
- 同一次任务技术失败时使用原种子恢复，不会偷偷重新抽取。
- 用户指定喜欢色时只追加，不影响随机主题数量。

## 输出内容

```text
00-classic/
  01-designs/
  02-front-full-body/
  03-angle-views/
  04-emotions/
  00-series-overview.png
01-随机主题/
...
00-all-images-overview.png
FEATURES.json
PROMPTS.md
QA.md
```

- 所有角色图均为独立方形 PNG，不需要从九宫格裁切。
- `FEATURES.json` 保存实际启用的功能。
- 每个主题可以生成分组拼图。
- `00-all-images-overview.png` 包含最终交付的全部原图，方便一次查看和比较。
- `PROMPTS.md` 保存角色 DNA、随机种子、主题和完整设计稿。
- `QA.md` 保存数量、尺寸、重复图、角度、情绪和原图哈希检查。

## 安装

```bash
git clone https://github.com/AndersonHJB/CodexSkills.git
mkdir -p ~/.codex/skills/generate-personal-ip-avatars
rsync -a CodexSkills/skills/generate-personal-ip-avatars/ ~/.codex/skills/generate-personal-ip-avatars/
```

安装后重启 Codex 或新建会话，并上传人物参考照片。

图片使用 Codex 内置图片生成能力逐张生成。拼图功能需要系统能够运行 ImageMagick 的 `magick` 命令。
