# 专属个人 IP 角色盲盒生成器

这是一个给零基础用户使用的 Codex Skill。你不需要会画画、懂配色、写提示词或有“艺术细胞”，只要提供一张清晰人物照片，就能获得可以直接比较和挑选的完整个人 IP 角色方案。

批量生成不是为了浪费生成额度，而是把插画师通常需要多轮完成的试色、动作提案、全身设定、角色转面和表情设计集中呈现。你可以像开盲盒一样发现意外适合自己的方向，再挑选少量方案继续精修。

全部原图完成后，Skill 还会生成一个可直接双击打开的离线 HTML 选择页面。它提供搜索、系列与类别筛选、缩略图密度、放大预览、上一张/下一张、收藏、淘汰、自动保存和 JSON 选择清单导出，比在文件夹中逐张翻看更适合几百张方案的筛选。

## 默认会生成什么

只要你没有明确写出“功能开关”或清楚地说“关闭/不要/只要某功能”，Skill 就会严格采用全部开启的默认配置，不会因为你只提到某几个功能而擅自关闭其他功能。

默认包含 1 个经典主题、8 个随机主题、2 个保证为浅色的随机主题，以及 8 张独立行业全身 IP。共 11 个完整主题角色；浅色主题不是把旧角色换个颜色，而会重新设计服装轮廓、动作、标志性配饰和涂鸦语言。每个完整主题生成：

- 8 张不同动作、发型处理、服装和标志性配饰设计
- 1 张正面全身照
- 8 张不同角度的全身角色转面照
- 24 张完整情绪图

因此默认数量为：

```text
每个主题：8 + 1 + 8 + 24 = 41 张
默认主题：1 个经典主题 + 8 个随机主题 + 2 个浅色主题 = 11 个
行业全身包：8 张
默认总数：11 × 41 + 8 = 459 张独立图片
```

这里的“每个角色”指每个主题中的同一个标准 IP 角色，不会把 24 种情绪再乘到每一张动作图上。这样既能覆盖角色系统，又避免无意义地膨胀到数千张。

如果你提供一个喜欢的机构、高校或品牌及其官方 VI 资料，机构品牌主题组默认追加 8 套完整角色系统，即再增加 `8 × 41 = 328` 张。以默认配置加一个机构为例，总数是 `459 + 328 = 787` 张。

如果你觉得 459 张太多，请明确写出功能开关关闭不需要的功能。Skill 的价值正在于可以自由组合，而不是强迫所有人都生成相同数量。

## 目前支持的全部功能

| 功能 | 默认 | 数量 | 说明 |
|---|---:|---:|---|
| 经典主题组 | 开 | 1 套 | 固定视觉基准，8 动作 + 全身 + 八角度 + 情绪 |
| 随机主题组 | 开 | 8 套 | 每人每次重新抽取颜色、服装、动作和配饰 |
| 浅色主题组 | 开 | 2 套 | 保证高明度，同时用深线稿维持辨识度 |
| 行业全身 IP 组 | 开 | 8 张 | 八个行业的服装、装饰、道具和姿态，全身独立图 |
| 机构品牌主题组 | 开、按输入生效 | 0 或默认 8 套 | 没有机构资料时为 0；提供官方 VI 后默认生成 8 套完整系统 |
| 基础动作设计 | 开 | 每套 8 张 | 不同动作、发型处理、服装细节和标志性配饰 |
| 正面全身照 | 开 | 每套 1 张 | 头到脚、鞋履完整、带主题装饰 |
| 八角度角色照 | 开 | 每套 8 张 | 正、侧、背与四个 3/4 方向，不能用镜像代替 |
| 全面情绪包 | 开 | 每套 24 张 | 从中性、开心到害怕、生气、疲惫等完整范围 |
| 分组拼图 | 开 | 不计原图 | 动作、角度、情绪和主题总览 |
| 全部图片拼图 | 开 | 不计原图 | 将所有独立原图各放一次，便于整体比较 |
| HTML 图片选择页面 | 开 | 不计原图 | 离线画廊、筛选、收藏、淘汰、放大预览和选择清单导出 |

机构品牌主题只借鉴经官方来源核实的颜色与色彩关系。默认不会复制校徽、Logo、标准字、制服或受保护标志，也不会暗示用户与该机构存在真实隶属、学历、任职或背书关系。

## 八角度全身转面包含哪些方向

每个启用主题生成以下 8 张独立、头到脚完整入镜的角色转面照：

1. 正面
2. 左前 45°
3. 左侧面
4. 左后 45°
5. 背面
6. 右后 45°
7. 右侧面
8. 右前 45°

不是把图片左右翻转冒充新角度；不对称的头发、衣服和配饰会按空间关系正确变化。

## 24 种情绪

情绪包包含：平静中性、放松、开心、大笑、兴奋、自豪、感激、如释重负、好奇、专注、坚定、惊讶、疑惑、害羞、尴尬、担心、害怕、伤心、哭泣、生气、不耐烦、嫌弃、疲惫和无聊。

每种情绪都是独立方形图片，并保持同一角色的脸型、发型、服装、主题色和构图一致。

## 随机主题盲盒

- 每次新任务都会得到新的随机种子和新主题组合。
- 随机主题会覆盖不同色相、明暗、冷暖和情绪氛围，不使用固定的八套预设。
- 随机种子和主题抽取结果会写进 `PROMPTS.md`。
- 同一次任务技术失败时使用原种子恢复，不会偷偷重新抽取。
- 用户指定喜欢色时只追加，不影响随机主题数量。

## 两套浅色主题

- 默认额外生成 2 套高明度、低到中饱和度的浅色盲盒主题。
- 两套浅色主题来自每次任务的新随机抽取，彼此必须属于不同色相与冷暖方向。
- 深色线稿负责保证头像尺寸下仍清晰，不会出现“颜色很浅但五官看不见”。
- 每套都会建立全新的服装、鞋履、配饰、动作和涂鸦系统，不允许只给已有角色换色。
- 如果不需要，请明确设置 `浅色主题组: 关` 和 `浅色主题数量: 0`。

## 八张行业全身 IP

默认行业覆盖数字技术、教育、建筑设计、健康科学、商业咨询、实验室科研、摄影媒体和环境规划。每张都会重新设计：

- 能辨认行业的衣服结构和鞋履
- 一个不会挡住身体的大道具
- 行业相关但无文字、无商标的背景装饰
- 不同站姿、手势和配饰

这些是创意职业形象，不代表用户真实拥有职业、执照、学位或机构认证。不会使用医疗红十字、警务军队徽章、政府标志、公司 Logo 或文字证书。

## 机构、高校或品牌 VI 主题

用户提供喜欢的高校、机构、品牌色或官方设计手册时，Skill 会先查询官方来源并记录：文档名称与日期、页面或栏目、Pantone、CMYK、RGB、色阶和辅助色关系。

默认生成 8 套完整系列，每套仍是 41 张。8 套必须拥有不同的服装轮廓、动作道具和装饰语言，不能只调整颜色深浅。

以清华大学官方 2023 中文 VI 手册为例，官方信息包括：

- 校色为紫、白两色
- 标准紫：PANTONE 259C，CMYK `65/100/0/20`，RGB `102/8/116`，屏幕十六进制 `#660874`
- 辅助玫红：PANTONE 7424C，CMYK `10/90/20/0`，RGB `217/51/121`，屏幕十六进制 `#D93379`
- 另有金、银、黑、白与紫色色阶应用

Skill 默认只使用这些颜色关系和抽象学术、创新、建筑、阅读、工程等视觉词汇，不把清华校徽、校名标准字或 Logo 直接放进生成图。

## 输出内容

```text
00-classic/
  01-designs/
  02-front-full-body/
  03-angle-views/
  04-emotions/
  00-series-overview.png
01-随机主题/
...
09-浅色主题/
10-浅色主题/
industry-full-body/
11-机构或高校主题/
...
18-机构或高校主题/
00-all-images-overview.png
00-selection-gallery.html
FEATURES.json
PROMPTS.md
QA.md
```

- 所有角色图均为独立方形 PNG，不需要从九宫格裁切。
- `FEATURES.json` 保存实际启用的功能。
- 每个主题可以生成分组拼图。
- `00-all-images-overview.png` 包含最终交付的全部原图，方便一次查看和比较。
- `00-selection-gallery.html` 可直接在浏览器离线打开，支持筛选、收藏、淘汰、放大预览、选择持久化和 JSON 导出。
- `PROMPTS.md` 保存角色 DNA、随机种子、主题和完整设计稿。
- `QA.md` 保存数量、尺寸、重复图、角度、情绪和原图哈希检查。

