# WeChat Sticker Publishing Specification

Snapshot date: 2026-07-12. Treat this as a fallback snapshot, not a permanent rule. Verify current official rules before each run when browsing is available.

Official entry: https://sticker.weixin.qq.com/cgi-bin/mmemoticonwebnode-bin/pages/home

## Current static album rules

- sticker count: 8–24; this skill intentionally produces exactly 20;
- each static sticker: PNG/JPG/GIF, 240×240, platform compresses above 500 KB;
- the album must not mix static and animated stickers;
- each sticker requires a 1–4 Han-character meaning word without punctuation.

## Publication assets

- detail banner: JPG/PNG, 750×400, one image, keep below 500 KB; no text; bright colorful opaque background; avoid white/transparent background; rich, relevant, story-like, and not distorted;
- album cover: PNG, 240×240, keep below 500 KB; transparent background; recognizable front half/full body; no white outline or jaggies; little excess whitespace; normally no text;
- chat icon: PNG, 50×50, keep below 100 KB; transparent background; recognizable front head; no white outline, jaggies, square frame, decoration, or excess whitespace;
- static thumbnails are generated by the platform.

## Copy limits

- album name: 1–8 Han characters, ideally no more than five; no punctuation or spaces; avoid duplicates;
- introduction: 1–80 characters;
- copyright: 1–10 characters; use the real copyright holder, designer, or studio;
- meaning word: 1–4 Han characters, no punctuation.

## Recommended current selections

- upload type: 静态表情;
- category: 卡通表情/其他;
- character/content: 人物角色 → 女人 for an adult woman reference; change when the subject differs;
- styles: 日常 + 软萌可爱 unless the actual pack differs;
- theme: 万能通用 unless the pack is intentionally themed;
- download region: 全球;
- listing region: 中国大陆 (platform-fixed in the current form);
- price: 免费;
- appreciation: off unless the user explicitly wants the extra 750×560 and 750×750 assets.
