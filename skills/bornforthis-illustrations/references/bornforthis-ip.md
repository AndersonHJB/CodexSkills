# Bornforthis IP

## 角色定义

Bornforthis 是中文正文配图的固定视觉 IP：一个带少年感的青年男性角色，安静、友好、自信，认真做一件略荒诞但成立的事。

默认每张图都出现 Bornforthis。他不是贴纸、表情包或站在角落里的品牌装饰，而是核心动作的执行者。

## 固定身份特征

按以下优先级保持同一个角色：

1. **浓密钴蓝短刺发**：顶部蓬松，碎刺参差向上；两侧明显更短，接近短寸渐层；前额发际线呈不规则锯齿形，不是齐刘海。基色约 `#1262D5`，暗部可用 `#0D55B2`。
2. **外扩的大圆耳**：双耳明显突出于头部两侧，接近半圆，内部只有简洁的 C 形耳廓线；不要让头发或配饰把耳朵完全遮住。
3. **纸白圆方脸**：宽额头、圆润双颊、下半脸轻微收窄；不是尖下巴，也不是写实苍白皮肤。脸部使用平面的纸白色填充，约 `#F4F2EE` 或 `#FAFAFB`。
4. **两枚正圆黄色脸颊**：左右对称，位于眼睛下方；使用平面的金黄色圆形色块，约 `#FCD40B`，不是粉红腮红或渐变红晕。
5. **极简蓝色五官**：两条短而略粗的钴蓝眉毛；小型钴蓝圆点或椭圆眼睛，上方带一笔简洁弧形上眼睑；鼻子是极小的亮黄色点；嘴是一条短小的钴蓝单线条，默认安静友好的闭口微笑。
6. **无胡须、无眼镜**。不要用写实鼻唇、眼白加瞳孔的大眼结构或复杂面部阴影。

## 比例与轮廓

- 青年男性气质，但保留清爽少年感；不是儿童。
- 约 3.5–4 头身，大头、紧凑而轻盈，肩宽适中；不要为追求数字而拉长四肢，以全身身份参考的轮廓观感为准。
- 手和脚可以略大、略圆，但不要变成幼儿式两头身 Q 版。
- 远距离轮廓至少保留：参差向上的短刺发冠、两侧突出圆耳、大而圆方的头部、紧凑青年身体。
- 不用参考图中的宽松裤、大球鞋或夹克定义体型。

## 表情与性格

- 默认是安静、友好、自信的轻微微笑。
- 可以按场景改变眉眼和嘴形，但保持小型蓝眼、短眉、黄色圆脸颊和极简单线嘴。
- 认真、专注、天然有点笨拙，但不装可爱。
- 冷幽默：角色自己不觉得好笑，画面却让人会心一笑。
- 遇到复杂系统时像一个真的在上班的创作者或操作员。

## 服装与配饰必须可变

服装不是身份特征。每张图按主题重新设计造型：

- 先根据动作和语义决定穿着，再选择最简单、最清楚的服装。
- 可以穿 T 恤、衬衫、卫衣、外套、工装、围裙、实验服或其他合适服装；不要形成固定制服。
- 耳机只在音乐、音频、专注或明确要求的场景出现。
- 相机、相机包、书、笔记本、腰带、腕带和球鞋只在场景需要时出现。
- 颜色服从当张图的克制配色；服装不必固定为蓝黄。
- 无语义需要时，不要复刻参考图的耳机、黄上衣、蓝黄夹克、白 T、米色阔腿裤、蓝黄球鞋、相机或点赞姿势。

无论如何换装，都必须保留钴蓝短刺发、外扩圆耳、纸白圆方脸、黄色圆脸颊和极简蓝色五官。

## 常见职责

让 Bornforthis 承担核心动作，例如：

- 搬运、分拣、压缩或连接信息。
- 拉线、扶梯、搭桥、守门或修补断点。
- 操作一台低科技怪机器。
- 把抽象概念折叠、拆包、称重或变成具体物件。
- 卡在流程里，再亲手把流程恢复运转。
- 记录、标记、筛选、推、接、塞、捞或回收。

## 禁止

- 不要改变固定脸型、发型、耳朵、脸颊颜色或五官结构。
- 不要黑发、长发、卷发、齐刘海、尖下巴、粉红腮红、写实肤色、胡须或眼镜。
- 不要巨大动漫眼、写实嘴唇、复杂鼻子或成人写实身材。
- 不要把耳机、夹克、相机、书或任何服装配饰画成默认标配。
- 不要让角色只站在角落里看，也不要让角色抢走结构表达。
- 不要画成精致商业吉祥物、3D 角色或幼儿式两头身卡通。
- 不要纯色平涂；所有色块都要有蜡笔或马克笔斜线笔触。

## 判断标准

缩小画面后，如果仍能凭“蓝色短刺发 + 外扩圆耳 + 纸白圆方脸 + 黄色圆脸颊”认出 Bornforthis，身份合格。

如果去掉 Bornforthis 后核心隐喻仍完全成立，说明角色太装饰；重写构图，让他成为动作主体。

如果换掉衣服或拿掉耳机就认不出角色，说明把可变造型误当成了身份；重做角色。
