# Xiaohongshu Caption Patterns

Use these rules when producing `小红书发布文案.md`.

## Deliverables

Always include:

1. `标题备选`: 5 titles, preferably within 20 Chinese characters when possible.
2. `整帖统一发布文案`: one caption for the full carousel, not one caption per image.
3. `图片顺序说明`: explain how each image supports the unified caption.
4. `互动引导`: one comment or private-message action.
5. `标签组合`: grouped hashtags with 8-15 relevant options.

## Caption Structure

Use this structure by default:

```text
[Hook: pain point / result / question]

[Empathy: why the reader is stuck or why the topic matters]

这组图整理了：
1. [Image 1 role]
2. [Image 2 role]
3. [Image 3 role]
4. [Image 4 role]

[Value: what the reader can do next or save]

[CTA: ask for comment, save, or DM keyword]
```

## Title Patterns

Use 2-3 of these patterns, adapted to the topic:

- Pain point: `零基础学AI编程，别乱刷课`
- Result: `用 Codex 把代码学明白`
- Audience: `学生/职场人都能学的 AI 编程`
- Curiosity: `为什么你学 AI 总是卡住？`
- Checklist: `AI 编程入门路线整理好了`

Avoid clickbait that overpromises. Do not write titles that imply guaranteed income, guaranteed job outcomes, or unrealistic learning speed.

## Tag Strategy

Prefer relevance over quantity. Group tags like this:

- Core topic: brand, main offer, primary skill.
- Audience: zero-base learners, students, professionals, creators, founders.
- Scenario: learning plan, project practice, productivity, portfolio, tutoring.
- Long-tail search: concrete phrases users may search, such as `#Codex教程`, `#AI编程入门`, `#Python零基础`.

For final output, provide 8-15 tags. Put the strongest 8-12 tags in the recommended line.

## Style

- Write in Simplified Chinese.
- Use direct, useful phrasing. Sound like a creator explaining a real solution, not a hard-sell ad.
- Prefer short paragraphs and bullets.
- Include "收藏" only when there is concrete reference value.
- Include "私信关键词" only when the user has a CTA or conversion goal.
- Keep commercial claims compliant and conservative.
