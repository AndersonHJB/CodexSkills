# AI 短剧制作包（short-drama-pack）

给一个剧本，一次性交付做 AI 短剧需要的全部文字物料：

- 角色多视图提示词
- 场景提示词
- 场景关联表
- 角色音色
- 21:9 分镜脚本
- 后期清单
- 一个离线 HTML 查看页

每样都是独立文件，方便分别上传、查看和复制。

默认风格是国漫 3D 半写实，默认画幅是电影宽银幕 21:9。分镜按视频平台的「片段 → 分镜」格式输出，例如：

```text
本片段场景设定在: @场景分组-场景名。生成一个由以下4个分镜组成的视频。
分镜1[时长: 8s]: 在@场景分组-场景名，全景，中心构图，平视机位，35mm……@角色分组-资产名……说：“台词”
```

## 交付什么

每部剧在剧本所在目录生成一个 `<剧名>_制作包/` 文件夹：

| 文件 | 内容 |
|---|---|
| `00_总览.md` | 数量统计、制作顺序、资产上传清单（平台上按这些名字建）、替你做的决定、没核实的事、校验结果 |
| `01_角色多视图提示词.md` | 风格锁、负面词、每个角色的 DNA，以及定妆多视图、六表情、状态变体的完整提示词 |
| `02_道具提示词.md` | 道具固定外观表和道具设定图 |
| `03_场景提示词.md` | 可整份交给出图 AI 按编号批量生成的场景提示词，带执行说明、参考图顺序和空间设定 |
| `04_场景关联表.md` | 场景分组层级、父子关系、参考图、人物站位，以及每张场景图、每个角色资产用在哪些分镜 |
| `05_角色音色.md` | 固定音色（长版、短版、英文版）、语速、试听文本、声音区分表、逐句表演指令 |
| `06_分镜脚本.md` | 导演阐述、音乐进出、片段总表、可整段粘贴的分镜脚本、导演备注、镜头一览 |
| `07_后期清单.md` | 字幕、定格、叠化、人声处理，以及按分镜排列的台词表 |
| `index.html` | 以上全部内容的离线查看页：分标签浏览、搜索、代码块和 `@` 引用名点一下就复制、明暗模式 |
| `project.json` | 以上所有文件的数据源 |

## 它是怎么保证不出错的

所有设计先写进一份 `project.json`，再由 `scripts/render.py` 统一生成全部文件。分镜里的 `@分组-名称` 和上传清单来自同一份数据，名称不会一处一个样。

渲染时会自动检查二十多类问题，例如：

- 剧本台词是否逐字、按顺序都在分镜里。
- 每个片段是否超过 30 秒或 5 个分镜，台词加动作是否塞得下。
- 场景参考图的出图顺序、复用关系、父子关系是否成立。
- 提到了不在画面里的角色、某一镜的道具没写固定外观。
- 画外音没写嘴闭着、画面里要出字、提示词里写了字幕或定格。
- 试听文本字数、音色长度、素材总时长与剧本的比例。

技能里还写着做《堵王加冕》时多轮审查总结出的规则：

- 场景状态要对上剧情那一刻。
- 跟着人走的道具不画进场景图。
- 每个分镜要自给自足。
- 反打机位左右相反。
- 少用否定句。
- 字幕和定格留给后期。

## 使用

把剧本文件路径或正文发过去，例如：

```text
使用 $short-drama-pack，把这个剧本做成完整的制作包：/path/to/剧本.txt
风格用国漫3D半写实，画幅 21:9。角色参考图在 /path/to/角色参考图/。
```

在 Claude Code 里可以输入 `/short-drama-pack`，或者直接说“把这个剧本做成制作包”。

可选输入：

- **角色参考图**：真人照片或已有角色图都行，会从图里提取角色 DNA。
- **风格和画幅**：不给就用默认值。
- **平台格式**：你的平台格式不同，就给一段示例，技能会照它输出。
- **平台上已有的名字**：平台已经自动建好了角色或场景名，告诉它，技能会照用。

## 交付后的制作顺序

1. 按 `01` 出每个角色的定妆图，挑定后再用它做参考出表情和状态变体，按资产名上传到平台。
2. 把 `03` 整份交给出图 AI 按编号生成场景图，主设定图先自检。
3. 按 `04` 在平台上逐字新建场景分组和名称，复用的位置直接选同一张图。
4. 按 `05` 为每个角色造一次音色并固化，平台能绑定就绑在角色上。
5. 把 `06` 的每个片段整段粘贴到平台，确认 `@` 变成了引用。
6. 按 `07` 加字幕、定格、叠化，处理人声。

## 修改

要改任何内容，改 `project.json` 后重新运行：

```bash
python3 ~/.codex/skills/short-drama-pack/scripts/render.py <制作包目录>/project.json
```

所有 md 和 html 会一起更新。不要手改生成出来的 md，下次渲染会被覆盖。

## 说明

- 技能只生成文字物料，不直接调用出图或视频模型。
- 提示词的实际出图、出片效果，需要在你使用的平台上抽卡验证。
- 文档里的音色工具限制来自 2026 年 10 月的调研，使用前以各家当时的官方说明为准。
