## 1. 总体思路

- **先找全片的“反差引擎”，再让镜头、声音为它服务。** 《堵王加冕》的引擎是“老公按灾难大片演，老婆按日常生活演”，于是：
  - 拍老公用低角度、长焦、硬光、慢动作、交响乐。
  - 拍老婆用平视、固定机位、自然光、无配乐。
  - 音乐每次都被老婆一句话切断。

  换一部剧，引擎可能是“职场黑话对上直球”“古人穿越进外卖站”。先用一句话写出它，放进 `director.logline`，所有设计都从这里推出来。
- **一切以“出图和生成时不穿帮”为准。** 视频模型每个分镜只看到这一个分镜的文字和参考图。上一镜的状态它不记得，所以每个分镜都要自给自足。
- **能用数据保证的，不靠注意力。** 名称、时长、台词覆盖都交给渲染器核对。人的注意力留给表演和连续性。

## 2. 角色

**风格锁**：每条角色提示词开头都带。默认写法（国漫 3D 半写实）：

```
国漫3D半写实风格，高精度3D角色建模，CG动画电影质感。真实人体比例（约7头身），五官比例严格按角色 DNA，在写实基础上轻度风格化、轮廓干净利落；皮肤细腻带次表面散射，保留真实肤色、年龄感和少量皮肤纹理；头发为成束分片的3D发丝建模；服装为写实PBR布料材质，褶皱自然。电影级柔和布光，虚幻引擎5渲染质感，细节丰富，{题材}题材。
```

- 把 `{题材}` 换成这部剧的题材，例如“现代都市家庭生活”“雨夜城市街头”“民国上海”。
- 不要写“眼睛略大有神”这类统一的五官要求，它会把几个角色的脸拉向同一张脸。五官以每个角色的 DNA 为准。

**负面词**：

```
真人照片，实拍摄影，二次元平涂，赛璐璐，Q版，大头小身，欧美卡通比例，网红脸，年轻化，过度美颜磨皮，塑料皮肤，蜡像感，欧美面孔，古装，仙侠元素，多余手指，畸形手，肢体错位，文字，水印，logo
```

“古装、仙侠元素”是因为国漫风格的模型默认偏仙侠。古装剧要删掉这两项。

**多视图版式**：

```
角色设定多视图转面图，横版16:9，纯净浅灰色无缝背景。同一个角色、同一套服装，从左到右依次排列四个全身像：正面、左前3/4侧面、正左侧面、背面；画面最右侧上下两格为头部特写：正面头像、3/4侧面头像。四个全身像头顶与脚底对齐在同一水平线，自然直立站姿，双臂自然下垂略离开身体，表情中性平静。均匀柔和的影棚平光，无强烈投影，无场景，无道具，无文字标注。
```

设定图用 16:9 即可，它不是成片画面。

“无场景、无道具、无文字标注”“空镜，无人物”这种标签式的“无 X”是出图提示词的惯用写法，可以用。第 4.5 节说的“少用否定句”，指的是在描述画面内容时写“没有工具箱”“看不到马桶”这类句子。

**DNA 段**：写成一段固定文字，所有提示词原样粘贴，不改同义词。

- 内容依次是：性别、年龄、身高、体型、脸型、肤色、眉眼、鼻、嘴、发型、耳朵等突出特征。
- 有参考照片时逐张看图提取，保留皱纹、晒斑、发际线、胖瘦这些“不好看但真实”的特征，并在提示词里写“不要年轻化、不要变瘦”。模型默认会美化，喜剧角色被美化就不好笑了。

**配色与剪影**：

- 每个角色一个主色，彼此拉开，也要和主场景的大色块拉开。例如沙发是墨绿，角色就别穿墨绿。
- 检查方法：把每个角色的主色和他出场的每个场景的主色调并排列出来，撞色的就改。
  - 夜戏、雨戏里穿深色衣服的角色会融进背景，给他加一件反光背心、亮色围巾之类的亮色配件。
  - 角色身边不要堆同色的道具和陈设。
- 体型和发型也要拉开，闭上眼一想就能分出谁是谁。

**资产怎么拆**：

- 定妆多视图，每种完全换装的造型一张。
- 状态变体：同一套衣服的不同状态，例如头发凌乱、衣服湿、裹毯子、手里拿着工具。以定妆图为参考，用 `state` 写这次改变了什么，渲染器会自动带上风格锁和 DNA。
- 版式：
  - 多个机位反复出现的状态用多视图。
  - 只出现一两次的状态用单张全身。
- 六表情：2 行 3 列，每格写清楚表情。表情从剧本里这个角色的关键情绪挑。
- 资产名用 `角色名_造型`，例如 `老公_颁奖六视图`、`蓝天_救援版`、`老公_战损状态`。平台按名字引用，名字要短、不重复、不含连字符。

**画面里的字**：纸条、横幅、招牌上的字，提示词里一律写“空白”“纯色素面”，后期再加。模型写中文常出错字。剧情靠一个字成立时，例如谐音梗，错一笔就全废了。

**多人同框**：再出一张身高对比图，锁定身高和体型关系。

## 3. 道具

- 只为反复出现、或者对剧情有用的道具出图，例如奖杯、工具、关键物件。
- 一张图排齐所有道具，纯色背景、互不遮挡、不写文字。
- 道具分两类：
  - **固定道具**：家具、电器、墙上的钟，画进场景图。
  - **跟着人走的道具**：杯子、手机、手套、工具，交给角色资产或分镜文字，不画进场景图。画进去的话，合成人物后就会出现两份。

## 4. 场景

### 4.1 先写空间设定

在写任何场景提示词之前，先把每个地点写清楚：

- 墙、地、顶的材质颜色。
- 固定家具和它们的左右位置。
- 门朝哪边开、合页在哪侧。
- 窗在哪面墙，光从哪边来。
- 地点之间怎么连通，例如走廊口开在沙发墙右端。

放进 `space`。所有场景提示词只从这里取词，同一物件在不同提示词里逐字一致。《堵王加冕》的审查查出过这些问题，全是空间设定没写死造成的：

- 挂钟在走廊口左右两边都出现过。
- 地垫横着铺，人躺不下。
- 水龙头被画到了另一面墙。

### 4.2 拆场景图

- 一个“地点 × 状态 × 时间 × 机位”出一张图，命名 `地点_状态_时间`，例如 `厕所区域_反打进水_白天`。
- 每个地点先出一张主设定图，即最常用的全景机位。其余图都从它派生。主设定图要写 `check` 自检要点，因为它错了，后面全错。
- 剧情会用到的机位都要有图：
  - 全景。
  - 门口：人物进出。
  - 反打：镜头在房间里朝门口拍，用于表情戏。
  - 低机位：躺、蹲、倒地。
  - 道具特写。
  - 窗景、钟这类时间镜头。
- 状态按剧情推进拆，例如干净、溅水、进水、退水。时间按剧情时间线拆，例如清晨、中午、黄昏、夜晚。
- 平台已经有的场景位，名字照用。两个位置是同一个画面时用 `reuse_of` 复用，不要重新生成，否则同一个房间会变成两个房间。

### 4.3 写场景提示词

每条提示词都要完整、可以单独使用，结构是：

1. 风格句：`国漫3D半写实风格，3D场景概念设定图，CG动画电影质感，写实PBR材质，虚幻引擎5渲染质感，细节丰富。空镜，无人物。`
2. 地点和机位：在哪、镜头在哪、朝哪拍、机位高度，以及画幅。画幅直接写 `{ratio_phrase}`，渲染时会换成 `meta.ratio_phrase`。
3. 构图：画面左、中、右各是什么，上下沿切在哪。
4. 物件和状态：从空间设定里逐字取词，再写这一刻的状态。
5. 光线：时间、光从哪来、什么颜色。

有参考图时，另写一句 `prefix`，说清每张参考图管什么，例如“与第一张参考图是同一个机位；门内的进水状态与第二张一致”。不要把提示词写成“以参考图为基础只改 X”：出图工具不支持参考图、或者只能传一张时，这种写法就不成立了。

### 4.4 21:9 构图

- 超宽画幅会逼模型把房间撑大。小房间要写真实尺寸，例如“宽约2.5米、进深约1.6米”，并写“空间紧凑”“正面一点透视”。
- 两端必须交代放什么。窄走廊要占画面中央五分之一，左右用相邻房间的物件填满。
- 竖向装不下时，写清上下沿切在哪，例如“上沿切在磨砂小窗的上沿附近，吊顶在画外”。
- 反打机位的左右与正打相反。每条反打都写明画面左侧、中央、右侧各是什么，否则模型会照抄参考图，把空间镜像。

### 4.5 不能入画的东西

剧本靠表情和音效交代的东西（例如马桶里、尸体、血腥）在所有场景图里都不入画：

- 用物件挡住，例如盖子合着、人的身体挡住。
- 机位朝相反方向，例如镜头在马桶位置朝门口拍。
- 写“只取……”“……在画面外”。

正面描述比“不要出现 X”可靠，因为否定句会把 X 这个词喂给模型。

### 4.6 时间道具

- 挂钟、窗外天色要和剧情时间对上：清晨的钟指 8 点，救援时指 11 点，黄昏指 6 点。
- 时间流逝镜头不要让模型转动指针，它画不好。出两张同构图、不同时刻的静帧，后期叠化。

### 4.7 03 文件的执行说明

渲染器会自动写入执行说明，告诉出图 AI 怎么用这份文件：

- 按编号生成。
- 原样使用提示词。
- 参考图怎么传，前缀怎么加。
- 复用的不生成。
- 主设定图先自检，最多重出 3 次，仍不合格就停下交给用户。

## 5. 音色

**固定音色与表演分开写**：

- 固定音色只描述天生的嗓子：年龄感、音高（同性别内偏高、中、偏低）、质感、语速、口音、气质。
- 不写条件句，例如“慌了会破音”。写了，造出来的嗓子每句都会破音。
- 不写效果器，例如混响、电话音。
- 不写数字，例如赫兹、字每秒、几成气声，模型不读。
- 不写否定句，例如“不甜不嗲”。

**三个版本**：

| 版本 | 写法 | 原因 |
|---|---|---|
| 长版 | 中文，80–150 字，不超过 200 字 | 火山音色设计限 200 字 |
| 短版 | 名词短语，15 字以内，例如“厚实圆润、明亮饱满的青年男声” | 嵌进视频提示词，每镜逐字重复 |
| 英文版 | ElevenLabs 模板：`Native Mandarin Chinese. Male, early 30s. Studio-quality recording. Persona: … Emotion: … <音质、语速>` | 只吃英文的工具用；另附一个英文短版给 Veo |

**区分度**：

- 几个角色在音高、语速、质感上要拉开。
- 最容易撞的是表演相近的两个人，例如都冷面，要靠质感和语速区分。
- 年龄漂移要写进验收要点：中老年女声最容易被做成年轻女声，老年男声容易被做成虚弱老人。

**试听文本**：

- 只放基础状态的句子，不放喊叫、虚弱、旁白，否则会把这种状态烤进嗓子。
- 按汉字计，不含标点，至少 100 个汉字；含标点不超过 300 字。
- 剧本里紧张、恳求、喊叫的句子不放，例如“大爷，就这一单，超时要扣钱”。台词不够时，补写这个角色平常语气的句子，并在 `audition_note` 注明哪些是补写的。

**逐句表演指令**：每句台词写一条“这一句怎么说”：语气、语速、停顿、重音、音量相对变化。

**其他要写进 `notes` 的**：

- 合声：几个人、什么声音、速度统一到谁。
- 非台词人声：喘息、呼气、闷哼。
- 多音字读音。
- 谐音梗要靠字幕区分。
- 戴口罩的闷声后期处理。

**全片同一个嗓子**：每个角色在造音色工具里只造一次，固化成音色 ID，之后全片引用这个 ID 或同一段参考音频。每次重新用文字描述，得到的会是不同的人。

## 6. 分镜

### 6.1 切片段

- 按剧本节拍切片段：每个片段一个完整的小包袱或一个动作段落。
- 片段时长不超过 `max_segment_seconds`（默认 30 秒），分镜数不超过 `max_shots_per_segment`（默认 5 个）。
- 一个分镜只用一张场景图。需要切到另一个空间时，拆成新分镜。
- 素材总时长通常是剧本标称时长的 1.3 到 1.6 倍，给剪辑留头尾。这是正常的，交付时告诉用户。

### 6.2 分镜文字的写法

开头固定：`在[[场景ID]]，景别，构图，机位高度/角度，焦段，运镜。`

后面依次写：

1. 光线和声音氛围。
2. 人物站位：画面左、中、右，前景还是背景。
3. 动作，一个接一个。
4. 台词：谁、怎么说，再接台词，例如 [[W]]平静地说：“地上有水。”说话人写在这一句的主语位置，渲染器靠它找说话人。
5. 结束时的状态。

具体要求：

- 画面里每个角色在这个分镜第一次出现时写成 `[[资产ID]]`，后面可以用“他”“她”。同一个分镜里换造型时，用新的资产 ID。
- 不在画面里的角色不写 `[[ID]]`，写“画面外的老公”，否则模型会把他画进来。
- 资产要和那一刻一致：造型、状态、手里拿着什么。角色参考图里手上拿着的东西，比如工具箱，如果这一刻已经放下了，要正面写出他现在两只手在干什么。
- 写「画面左侧、右侧」之前，先看这张场景图的 `stand`：人在这张图里能站在哪。斜机位下，站在门口的人往往在画面中间偏右，写成“画面左侧”，模型会把他放到不能站的地方。

**自给自足清单**：模型只看得到当前这一镜，下面几样每一镜都要重新写：

- 道具的外观：用 `[[道具ID]]`，渲染器展开成同一段描述。
- 两只手各拿着什么。
- 人物之间的距离：递东西、撑伞、碰触之前，先写两人走近。
- 上一镜移动过的东西现在在哪，例如伞歪过去、袋子挂到手腕上、门开着。
- 音乐还在不在：在切断点之前的分镜里写“鼓点仍在”。

### 6.3 时长怎么算

- 普通话每秒约 4 个字。镜头里的台词按每秒 3 到 3.5 个字给时长，再加上动作和停顿。
- 说话慢的角色（老人、沉稳的人）每秒约 3 字，说话快的约 5 字。
- 庄重念稿、旁白每秒 2.5 到 3 字。
- 一个分镜里塞的动作不要超过三四个。站起、走两步、坐下这种全身动作，每个算 1.5 到 2 秒。在 `beats` 里写动作数，渲染器会和台词一起算。
- 位移按距离另算：穿过一段走廊、骑车穿过画面、爬一层楼，各给 2 到 3 秒。
- 剧本专门写了“半天说不出话”“沉默两秒”的情绪停顿，要给足，这往往是全片最满的一拍。
- 超过 40 个字的长台词，在句号处拆成两个分镜。

### 6.4 视频模型容易出错的地方

| 情况 | 写法 |
|---|---|
| 旁白、画外音 | 写“他的嘴全程闭着，画面外响起他本人声音的旁白（画外音）”；人物在画面里时写“嘴唇合拢” |
| 说话人背对镜头或只露脚 | 写“她的脸在画面外；画面外传来她的声音（画外音，女声）” |
| 拟声词、音效 | 不放双引号，写“门铃叮咚响了一声（环境音效）”，否则会被人念出来 |
| 齐声 | 写“三个人同时开口，两个女声和一个男声整齐地叠在一起，三个人的嘴同步开合”；后期备注“只出一个人声就分别配音叠轨” |
| 手机屏幕、写了字的纸、演讲稿 | 写“屏幕朝向她自己，镜头只看到手机背面” |
| 揭晓纸上或屏幕上的字 | 先拍背面；下一镜从看纸那人的肩后往下拍，纸面朝向他，也朝向镜头，纸面空白，字后期合成。不要用对面机位拍“正对镜头”的纸，那样他看的是纸背面 |
| 观众必须读到的消息 | 发信人画外音，加后期消息气泡。这时消息文字才算台词，写进 `script_lines` |
| 不在画面里的角色 | 写“画面外左侧的某某”，不写引用 |
| 定格、字幕 | 不写进提示词，写“保持姿势一动不动，镜头静止”，定格和字幕放进 `post` |
| 停在动作中途，例如倒到一半 | 写“这个分镜结束时他仍斜在半空”，下一镜从这个姿势接 |
| 否定句 | 改成正面描述：“没有工具箱”改成“双手握着疏通器” |
| 两只相似物件，例如两个水龙头 | 用位置区分：“画面左下角墙上那只低位水龙头” |
| 表情戏 | 放在能看到脸的机位；关键反应放进双人镜头，不要切到看不到脸的机位 |

### 6.5 导演手法

- 两套镜头语言对应两种人物，见第 1 节。
- 音乐的进出是节奏的一部分。喜剧里常见的做法是：谁的情绪在“演”，音乐就为谁响，再被另一方一句话切断。
- 先在 `music_cues` 里列出全片音乐的进出表：在哪一镜进、哪一镜出、被什么切断。每一处进出只发生一次。如果某一镜已经“戛然而止”，后面就没有东西可停了。
- 重复的问答用同样的机位和语调。重复本身就是节奏。
- 包袱前留一拍静音，包袱后不留气口。
- 站位和轴线全片固定，写进导演阐述。例如“客厅里老婆在画面左侧，老公在右”。
- 导演阐述里的每一条全片性说法，例如“全部固定机位”“全用 50mm”“门开后转暖”，都要和每一镜对得上。写完拿 06 末尾的「镜头一览」逐条核对，做不到的就别写成“全部”。

### 6.6 导演备注

每个片段写一句导演备注：这一段的包袱在哪，出片后重点检查什么，例如“检查躺着的老公有没有张嘴”。

## 7. 后期

后期清单里列：

- **字幕**：开场时间字幕、谐音梗字幕、结尾字幕。
- **定格**：用最后一帧冻结。
- **叠化**：时间流逝。
- **人声处理**：口罩闷声、混响，以及对话音量比例，例如冷面角色压到对方的六七成。
- **补救方案**：字写错了怎么办，齐声只出一个人怎么办。

渲染器会自动把每个分镜的台词抽出来做成台词表，配音和打字幕用。

## 8. 审查清单

渲染通过后，逐个片段、逐个分镜过一遍：

1. 剧本里这一段的每个动作、停顿、音效都在吗？顺序对吗？
2. 这个分镜的场景图状态，例如干净、进水、时间、门开关，和剧情那一刻一致吗？场景图里的钟、天色、沙发上的毯子对得上吗？
3. 每个角色用的资产，造型和状态，和这一刻一致吗？手里的道具和上一镜接得上吗？会不会出现两份？
4. 站位、朝向和上一镜接得上吗？反打的左右写了吗？
5. 有没有会让禁止入画的东西露出来的机位？
6. 画外音、背对镜头说话的人，写清楚嘴的状态了吗？
7. 有没有要求画面出字、出屏幕内容、做定格？
8. 时长装得下台词和动作吗？
9. 有没有否定句会把不想要的东西招进来？
10. 表演有没有违背反差引擎？例如让“认真的人”自己知道好笑。
11. 道具外观每镜都在吗？上一镜移动过的东西交代了吗？两只手够用吗？
12. 两人的距离够做这个动作吗？比如撑伞、递东西。
13. 揭晓纸面或屏幕时，视线逻辑对吗？看纸的人看到的是正面吗？
14. 音乐的进出前后一致吗？有没有在同一处停了两次？
15. 导演阐述里的“全部……”和「镜头一览」对得上吗？
16. 场景提示词内部有没有互相矛盾？比如前面写“窗里亮着暖灯”，后面写“只有岗亭是暖色”。
17. 反打和低机位里，离镜头最近的前景物件写了吗？
18. 素材总时长在剧本标称的 1.3 到 1.6 倍之间吗？
