# project.json 字段说明

`project.json` 是整个制作包的唯一数据源，`render.py` 从它生成所有文件。完整示例见 `examples/堵王加冕/project.json`。

## 目录

- 引用写法
- meta
- style
- characters
- props
- voices
- space、scene_rules、lighting
- scene_groups、scenes
- script_lines
- director
- segments
- music_cues
- post_global
- include（分文件）
- 最小示例

## 引用写法

在任何文本字段里写 `[[ID]]` 来引用角色资产、场景、道具或音色，渲染时统一展开。不存在的 ID 会报错误。

- 角色资产的分组是角色名：`[[H_HOME]]` 展开为 `@老公-老公_居家六视图`。
- 场景的分组是场景分组名：`[[S_TAP]]` 展开为 `@老公和老婆的家-厕所区域-厕所区域_水龙头特写_白天`。

- 道具：有 `group` 时展开成 `@分组-名称`（道具也上传到平台的情况）；没有时展开成它的固定外观 `desc`。
- 音色：`voices.characters` 里带 `id` 的一项（如 `V_H`），展开成它的短版音色 `short`。平台不能绑定音色、需要在分镜里写“用……说”时使用。

文本里写 `{ratio_phrase}` 会被替换成 `meta.ratio_phrase`，场景提示词里写画幅时用它，就不用每条手抄。

ID 只用英文字母、数字、下划线，建议有含义，例如 `H_AWARD`、`S_REV_FLOOD`、`P_THERMOS`。

自己起的分组名、资产名、场景名都不要含连字符 `-`：平台按「分组-名称」解析，多一个连字符就可能断错。平台自动起的名字照用，例如「老公和老婆的家-厕所区域」，同时在 `meta` 里设 `allow_group_hyphen: true` 关闭这条提醒。

## meta

| 字段 | 必需 | 说明 |
|---|---|---|
| `title` | 是 | 剧名 |
| `episode` | 否 | 集数，例如「单集」「第3集」 |
| `style` | 是 | 例如「国漫3D半写实」 |
| `ratio` | 是 | 例如「21:9」 |
| `ratio_phrase` | 否 | 写进提示词的画幅说法，替换文本里的 `{ratio_phrase}`。默认：画幅是 21:9 时为「电影宽银幕21:9横版」，其他为「<画幅>画幅」 |
| `logline` | 否 | 一句话故事 |
| `script_file` | 否 | 剧本文件名 |
| `max_segment_seconds` | 否 | 每个片段的时长上限，默认 30 |
| `max_shots_per_segment` | 否 | 每个片段的分镜数上限，默认 5 |
| `default_cps` | 否 | 推断不出说话人、或说话人没写 `cps` 时用的语速（每秒几个字），默认 3.5。旧名 `max_chars_per_second` 也认 |
| `seconds_per_beat` | 否 | 分镜里每个动作（`beats`）算几秒，默认 1.5 |
| `script_seconds` | 否 | 剧本标称时长（秒）。填了会检查素材总时长是否在它的 1.3 到 1.6 倍之间 |
| `allow_group_hyphen` | 否 | 分组名沿用平台自动起的、带连字符的名字时设为 true |
| `segment_header` | 否 | 片段头部模板，默认 `本片段场景设定在: {scenes}。生成一个由以下{n}个分镜组成的视频。`。可用变量：`{scenes}` 场景引用（逗号分隔）、`{n}` 分镜数 |
| `shot_line` | 否 | 分镜行模板，默认 `分镜{i}[时长: {dur}s]: {text}`。可用变量：`{i}` 序号、`{dur}` 秒数、`{text}` 分镜文字。模板里其他花括号原样输出 |
| `decisions` | 是 | 你替用户做的决定，一条一句话。空着会提醒 |
| `unverified` | 是 | 没有核实的事。空着会提醒 |

## style

| 字段 | 说明 |
|---|---|
| `character_style_lock` | 角色提示词开头都带的风格锁 |
| `character_negative` | 角色通用负面词 |
| `multiview_layout` | 多视图版式描述 |
| `scene_negative` | 场景通用负面词，出现在 03 的执行说明里 |

## characters

数组，每个角色一项：

| 字段 | 说明 |
|---|---|
| `name` | 必需。角色名，也是平台上的角色分组名 |
| `aliases` | 分镜里可能出现的别称，例如「琴声」，字符串数组，可选。渲染器用它检查“提到了这个人却没引用他” |
| `role` | 一句话定位，例如「主角，按灾难大片演」 |
| `color` | 主色，几个角色之间要拉开 |
| `silhouette` | 剪影特征 |
| `reference_image` | 原型参考图路径，可选 |
| `notes` | 补充说明，字符串数组，可选 |
| `dna` | 固定外貌段落，所有提示词原样粘贴 |
| `assets` | 角色资产数组，见下 |

每个资产：

| 字段 | 说明 |
|---|---|
| `id` | 必需。引用 ID |
| `name` | 必需。平台上的资产名，格式 `角色名_造型`，例如 `老公_居家六视图` |
| `type` | 显示用的类型说明，例如「定妆」「状态」「表情」，可选 |
| `use` | 用在哪些场次 |
| `refs` | 出这张图时要上传的参考资产 ID，按顺序。必须排在本资产前面 |
| `layout` | 「多视图」「表情」「单张全身」。组装提示词时用 |
| `outfit` | 服装描述。状态变体可以不写：没写时会沿 `refs` 找同一角色的上游资产继承 |
| `state` | 状态描述，例如“头发凌乱汗湿，袖子挽到手肘，衣服有水渍” |
| `expressions` | `layout` 为「表情」时的六个表情，字符串数组 |
| `ref_clause` | 自定义参考说明，覆盖默认那句，可选 |
| `extra` | 追加在最后的一句，例如手里拿的道具，可选 |
| `prompt` | 写了就原样使用，不再组装，可选 |
| `note` | 补充说明，可选 |

**提示词组装**：没写 `prompt` 时，渲染器按下面的顺序拼成完整提示词。DNA 和风格锁只在数据里写一次，每条提示词里都会原样出现，不会漂移。

1. 风格锁。
2. 参考说明：
   - 有 `refs` 时写“与参考图中的角色完全一致”。
   - 没有 `refs` 但角色有 `reference_image` 时写“以参考照片为原型，不要年轻化”。
3. DNA。
4. 服装。
5. 状态。
6. 版式：
   - 多视图：用 `style.multiview_layout`。
   - 表情：渲染器生成六宫格版式。
   - 单张全身：全身正面加一格面部特写。
7. `extra`。

**版式怎么选**：

- 每个角色的第一套造型用多视图。
- 会在多个机位反复出现的状态也用多视图。
- 只出现一两次的状态用单张全身。
- 每个角色一张表情。

## props

数组，每个道具一项：

| 字段 | 说明 |
|---|---|
| `id` | 引用 ID。会在分镜里出现的道具必须有 |
| `name` | 道具名 |
| `desc` | 固定外观，写成名词短语、不带句号，例如“不锈钢桶身、淡绿色盖子的双层保温桶”。分镜里写 `[[P_ID]]` 时原样嵌进句子，例如“把[[P_ID]]放到桌上”。有 `id` 又没有 `group` 时必需 |
| `keywords` | 道具的叫法，例如 `["保温桶"]`。分镜里出现这些词却没写 `[[P_ID]]` 时，渲染器会提醒 |
| `group` | 道具图也上传到平台时填分组名，此时 `[[P_ID]]` 展开成 `@分组-名称`，可选 |
| `refs` | 出道具图时的参考图，可选 |
| `prompt` | 道具设定图的提示词，可选。身高对比图这类整组设定图也放在这里 |
| `note` | 补充说明，可选 |

没有道具时写空数组。

## voices

| 字段 | 说明 |
|---|---|
| `characters` | 每个角色一项：`character`（必须和 `characters[].name` 逐字一致）、`id`（可选，写了就能用 `[[V_…]]` 引用短版音色）、`cps`（每秒几个字，用来核对分镜时长，写在这里而不是 characters 里）、`long`、`short`、`en`、`en_short`、`watch`（验收注意）、`audition`、`audition_note` |
| `compare` | 声音区分表：`{ "headers": [...], "rows": [[...], ...] }` |
| `lines` | 逐句表演指令：`{ "character", "where", "line", "direction" }`。`line` 逐字抄剧本，不带引号 |
| `notes` | 读音、合声、非台词人声、后期处理，字符串数组 |

## space、scene_rules、lighting

- **`space`**：空间设定，`[{ "area": "客厅", "items": ["……"] }]`，写每个地点固定物件的位置和左右关系。
- **`scene_rules`**：拍摄规则，字符串数组。例如什么永远不入画、哪些道具跟着人走。
- **`lighting`**：时间与光线表，`{ "headers": [...], "rows": [...] }`，建议按「场次 × 地点」排。

## scene_groups、scenes

- **`scene_groups`**：`[{ "name": "老公和老婆的家-厕所区域", "note": "……" }]`。
- **`scenes`**：按出图顺序排的数组。被引用的场景必须排在引用它的场景前面。

| 字段 | 说明 |
|---|---|
| `id` | 必需。引用 ID |
| `group` | 必需。场景分组名 |
| `name` | 必需。平台上的场景名，格式 `地点_状态_时间`，例如 `厕所区域_反打进水_白天` |
| `parent` | 平台画布上连在哪个场景后面（场景 ID），可选。不写时渲染器自动取 `refs` 里的第一张场景；平台已有布局时照平台的连线填。必须是场景、排在本场景前面。父场景在别的分组时，层级树里显示在本组第一层并注明 |
| `refs` | 出图时要上传的参考图（场景或角色资产 ID），按顺序 |
| `prefix` | 有参考图时加在提示词最前面的一句，说明每张参考图管什么 |
| `prompt` | 完整、可单独使用的提示词。不能写成「在参考图基础上只改 X」 |
| `use` | 用在剧本哪一刻 |
| `stand` | 人在这张图里能站在哪、处于画面哪个位置，例如“站在门前门垫上的人在画面中间偏右”。写分镜站位时对照 |
| `priority` | 取值见下 |
| `check` | 主设定图的自检要点 |
| `reuse_of` | 复用另一张场景图时填它的 ID，此时不写 `prompt`。必须指向排在前面的、本身不是复用的场景 |

`priority` 的取值：

| 取值 | 含义 |
|---|---|
| 主设定图 | 这个地点的源头图。可以有参考图，例如同一栋楼的另一个地点，用来统一材质 |
| 现有 | 平台上已经有的场景位 |
| 必加 | 被分镜或别的场景用到的图 |
| 按需 | 没有被任何分镜用到的备选图 |

被用到却标了「按需」时，渲染器会提醒。

## script_lines

剧本里全部台词，按出现顺序逐字抄写，包括旁白、齐声、画外音，字符串数组。渲染器会核对每一句是否按顺序出现在分镜的引号里。

- 剧本里的内层双引号照抄即可，核对时会忽略引号和标点。
- 一句台词可以拆进相邻两个分镜，例如在停顿处拆开，只要连起来逐字一致。
- 手机、纸条、屏幕上的文字默认不算台词，由后期叠字。只有决定把它改成发信人的画外音时才算，这时写进 `script_lines`，并在 `meta.decisions` 里说明。

## director

导演阐述：

```json
{
  "logline": "一句话",
  "sections": [ { "title": "两套镜头语言", "items": ["……"] } ]
}
```

## segments

数组，每个片段一项：

| 字段 | 说明 |
|---|---|
| `title` | 片段标题，例如「颁奖现场」 |
| `script_pos` | 剧本位置，例如「第一场」「第三场结尾」 |
| `note` | 导演备注：这一段的包袱在哪、出片后查什么 |
| `post` | 本片段的后期项，例如字幕、定格、叠化 |
| `shots` | 分镜数组：`{ "dur": 秒数（正整数，必需）, "beats": 动作数（可选）, "speakers": ["角色名", …]（可选）, "text": "在[[场景ID]]，景别……"（必需） }` |

片段头部的场景列表由渲染器自动生成，不用写。

台词写在中文双引号 `“”` 里，内层引号用单引号 `‘’`。拟声词和音效不要放进双引号，否则会被当成台词。

**说话人**：渲染器给每句台词找说话人，用来按他的语速算时长，并填 07 台词表。找法是取台词前面那一句里第一个出现的角色（`[[资产ID]]`、角色名或别称都算），所以说话人要写在这一句的主语位置，例如“[[W]]看着他，平静地说：“……””。推断不了的写法，例如一句里先出现被看的人，就在 `speakers` 里按台词顺序写明说话人。

渲染器用两样东西估算一个分镜需要多少秒，超过 `dur` 时提醒：

- **台词**：字数除以说话人的 `cps`。说话人取台词前最近出现的角色引用。
- **动作**：`beats × seconds_per_beat`。“站起来、走两步、拿起杯子”算 3 个动作。

## music_cues

全片音乐的进出表，可选，渲染在 06 的「音乐进出」：

```json
[ { "shot": "02-3", "music": "电子鼓点", "action": "戛然而止", "trigger": "小周看到备注" } ]
```

每一处进或出只能发生在一个分镜里。切断之前的那几镜，要在分镜文字里写明“鼓点仍在”。`shot` 编号不存在时会提醒。

## post_global

全片统一的后期处理，字符串数组。

## include（分文件）

数据太大时，可以拆成几个文件：

```json
{ "include": ["part_scenes.json", "part_segments.json"], "meta": { } }
```

分文件里的顶层键会按顺序合并进来：数组拼接，对象合并，其余覆盖。分文件里还可以再写 `include`。
