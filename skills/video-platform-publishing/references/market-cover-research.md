# Market Cover Research

Use this reference before designing covers or thumbnails.

## Research Pass

Search current comparable videos unless the user explicitly says not to search. Use web search, platform search, or image search depending on available tools.

Minimum reference set:

- 3-5 same-topic videos, such as the exact tool, product, platform, or problem.
- 3-5 same-format videos, such as tutorial, teardown, experience note, risk warning, or comparison.
- 2-3 strong creators or channels in the same niche when discoverable.

Suggested queries:

- `[topic] 教程 封面 site:bilibili.com`
- `[topic] 避坑 封面 抖音`
- `[topic] 小红书 封面`
- `[topic] tutorial thumbnail YouTube`
- `[tool] API risk tutorial thumbnail`
- `[platform] [topic] 费用 账单 避坑`

When platform search is unavailable, use broader web/image search and cite that references were market-adjacent rather than exact platform-native examples.

## What To Extract

For each useful reference, note:

- Hook type: fear/risk, gain/result, curiosity gap, checklist, before/after, proof/demo.
- Visual anchor: face, product UI, code, chart, bill, logo, device, real object.
- Typography: number of text blocks, font weight, text size, stroke/shadow treatment.
- Color system: background darkness, accent color, danger color, brand color.
- Layout: left text/right proof, face + screenshot, full-screen UI crop, label stickers, arrows/circles.
- Platform fit: mobile legibility, desktop thumbnail readability, save-worthy note style.

Summarize the pattern in 3-6 bullets before creating the user's cover.

## Design Translation Rules

- Use references to infer conventions; do not clone exact text placement, colors, or composition from one competitor.
- Preserve the user's video's proof points. Prefer actual frames, screenshots, results, and facecam from the video.
- Make one visual promise per cover. If there are multiple benefits, put the strongest one in the title/description instead.
- Put the highest-contrast words on the left or upper third for feed scanning unless the platform/reference set suggests otherwise.
- For technical tutorials, combine a clean UI proof screenshot with a large numeric or risk hook.
- For sensitive tactics, shift wording from "how to exploit" to "mechanism/risk/truth/avoid pitfalls".

## Platform Style Patterns

### 微信视频号

- Trust-first visual style. Avoid overly aggressive clickbait.
- Use practical labels: `新手先看`, `避坑`, `实测`, `讲清楚`.
- Face plus proof screenshot works when the creator has on-camera presence.

### 抖音

- Fast and emotional. Big hook, high contrast, simple proof cue.
- Common patterns: large number, danger label, before/after, red/yellow sticker.
- Make the cover readable at very small sizes.

### 哔哩哔哩

- Tutorial-search style. Larger context is acceptable than Douyin.
- Include product/tool keywords on cover when searchable, such as `Gemini API`, `Google Cloud`, `扣费`.
- UI proof and creator facecam often work for software tutorials.

### YouTube

- Reduce thumbnail text to the minimum. Title carries search keywords.
- Use a clear face/object/UI anchor and one strong curiosity phrase.
- Avoid dense Chinese paragraphs on the thumbnail; if Chinese, use large short phrases.

### 小红书

- Save-worthy note style. Use `真相`, `避坑`, `清单`, `别只看...`.
- 3:4 cover can include a title block, proof screenshot, and short checklist cue.
- Keep the design organized and practical, not too ad-like.
